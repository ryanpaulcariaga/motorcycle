# Motorcycle Comparison Feature

## Overview

Browse, search, filter, and compare motorcycles by specs (engine, body, performance, etc.).

## Requirements

- **Browse**: List all motorcycles with basic info (brand, model, year, MSRP, primary image)
- **Search**: Free-text search by brand, model, or category
- **Filter**: Dynamic filters per spec (numeric range, text, boolean, enum multiselect)
- **Compare**: Add unlimited bikes; side-by-side cards for ≤5 bikes, scrollable table for >5
- **SEO**: Server-rendered pages for search indexing
- **Responsive**: Mobile-first, works on all devices

## Out of Scope (MVP)

- Authentication / user accounts
- Upvotes, comments, reviews
- Admin UI for managing bikes/specs
- Analytics dashboard
